Preguntas frecuentes

Antes de operar

¿Necesito crear una cuenta?▾
No. Solo conectas tu wallet (MetaMask o Trust Wallet) o dejas tu correo para identificar la operación. No hay contraseñas ni perfiles que crear.
¿Qué pasa si pago y no me liberan el USDT?▾
Cada operación queda registrada con tu memo firmado. Además, el proveedor tiene una ventana de tiempo configurada para liberar tras tu pago — si no cumple, quedas respaldado por ese registro para reclamar.
¿Puedo cancelar una operación ya aceptada?▾
No. Una vez que un proveedor acepta y compromete el USDT, la operación no se puede revertir — solo completarse. Por eso es importante confirmar el monto y la plataforma antes de buscar operador.
¿Cómo se protege LS Cambios de estafadores?▾
Guardamos el correo y la wallet de cada operación. Quien incumple queda marcado y bloqueado para futuras operaciones en la plataforma.
